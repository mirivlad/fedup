# FedUp — кратко о проекте

**FedUp** — открытая система защищённого доступа через собственные серверы для личного и семейного использования. Проект рассчитан на Android, Linux и Windows; серверная часть — Linux. Исходный код будет публичным, но адреса действующих узлов и приватные ключи публиковать нельзя.

**Статус на 10 ноября 2026:** в коде уже есть экспериментальный Android → свой VPS → интернет по IPv4: HTTPS-вход по адресу/логину/паролю, автоматический ключ Android Keystore, клиентский сертификат без ручного обмена файлами, IPv4 TUN и DNS, HTTP/2 через TLS 1.3 и NAT. В изолированных Linux namespaces проверено изменение исходного IP. **Ни реальный телефон, ни публичный VPS ещё не прошли приёмку.** Небезопасный лабораторный издатель сертификатов, отсутствие стабильной подписи APK и защиты от утечек при авариях исключают повседневное использование.

## Главные принципы

- Не придумываем собственную криптографию. Используем поддерживаемые реализации TLS и стандартные криптографические примитивы.
- Собственная часть — протокол сеансов, учёт устройств, маршрутизация и управление, а не «секретный шифр».
- Незаметность **не гарантируется**. Измеряем сетевой профиль и прямо сообщаем известные ограничения.
- У каждого устройства отдельный ключ, который можно отозвать.
- Ошибка туннеля не должна незаметно отправлять защищаемый трафик напрямую.
- Для Android предполагается один активный VPN-сервис в пользовательском профиле. Список приложений определяет маршрутизацию, но не гарантирует, что другие приложения не заметят наличие VPN.
- На первом этапе один сервер; резервные входы и релейные узлы — позже.

Отдельный компонент fedup-netguard устанавливает и проверяет правила, которые сохраняются при аварии VPN-клиента. Пока такая защита проверяется **только в изолированных Linux namespace**, а не на обычном рабочем компьютере.
