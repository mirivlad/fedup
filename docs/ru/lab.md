# FedUp: первая экспериментальная сборка

Это **не VPN**, не прокси и не способ обхода ограничений. В репозитории есть Rust-библиотека кодирования кадров и стенд проверки защищённого соединения двух процессов на одной Linux-машине. Сервер специально запрещает прослушивание внешних IP-адресов.

## Что реализовано

- Rust workspace: fedup-protocol и fedup-lab.
- Формат кадров v1: максимум 64 КиБ, контроль версии, типа и идентификатора потока.
- TLS 1.3 с взаимной проверкой сертификатов (mTLS) через rustls.
- Один Ping/Pong; никакой передачи пользовательского интернета через туннель.
- Unit-тесты парсера и GitHub Actions smoke test.

## Проверка на Debian / MX Linux

Требуются cargo, rustc, openssl, python3 и инструменты сборки.

```bash
git clone https://github.com/mirivlad/fedup.git
cd fedup
cargo test --workspace --all-targets
cargo build -p fedup-lab
bash tests/lab-smoke.sh
```

Сценарий создаёт временный тестовый CA, клиентский и серверный сертификаты. Они удаляются после проверки. Нельзя использовать их в реальной инфраструктуре.

## Чего пока нет

TUN, DNS, маршрутизации, TCP/UDP-туннелирования, интерфейсов Android/Windows, админ-панели, выдачи и отзыва устройств, HTTP/2-транспорта, резервирования узлов и измерений DPI.
